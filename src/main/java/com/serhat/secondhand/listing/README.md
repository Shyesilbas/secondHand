# Listing Domain

Manages the 6-vertical polymorphic product catalog (`VehicleListing`, `ElectronicListing`, `RealEstateListing`, `BooksListing`, `ClothingListing`, `SportsListing` extending `Listing` via JPA joined inheritance), rule-driven attribute validation, spec snapshotting, price history (`@TrackPriceChange`), and view/social proof metrics.

## Business Rules & Invariants
- **Joined Polymorphism & Rule-Driven Validation:** Base `listings` rows join to `vehicle_listings`, `electronic_listings`, `real_estate_listings`, `book_listings`, `clothing_listings`, and `sports_listings`. `ListingValidationEngine` runs location checks, category `CategorySpecValidator`s (`*TypeRulesValidator` + `*HierarchyValidator`), and `ListingAttributeValidator` (`listing_attribute_definitions` stored in `listings.attributes` JSONB with GIN index `idx_listings_attributes` (`jsonb_path_ops`, V39)).
- **Deterministic Spec Snapshotters:** `VehicleSpecSnapshotter`, `ElectronicSpecSnapshotter`, and `BooksEditionSnapshotter` overwrite client inputs with non-null verified catalog facts on create and update; unlinked listings remain allowed as unverified.
- **Lifecycle & Price History (`ListingStatus`):** Transitions across `DRAFT`, `ACTIVE` (publishes `NewListingCreatedEvent`), `INACTIVE`, `SOLD`, and `DELETED` (accepted offers hold stock in Redis, not through a listing status; `RESERVED` was dropped in V65). Modifying `price` triggers `@TrackPriceChange` (`PriceHistoryAspect`, `price_history` table). Only `ListingStatus.isPublicBrowsable()` statuses are public; `/filter` and `/status/{status}` reject the rest (`INVALID_LISTING_STATUS`).
- **Creation fee scope:** only types with `ListingType.chargesCreationFee()` (VEHICLE, REAL_ESTATE) pay the listing fee (`Listing.requiresCreationFee()`); other verticals are published directly via `PUT /{id}/publish` and pay commission on sale (`escrow` hub). The enum catalog exposes `listingFeeConfig.feeBearingTypes` to the frontend.
- **Moderation Takedowns:** `ListingModerationService` moves `ACTIVE` listings to `INACTIVE` for complaint sanctions without an owner check; it requires the caller's transaction.
- **Best Sellers:** `ListingBestSellerService` ranks `ACTIVE` listings by units sold; only IDs are cached.
- **Debounced Views & Social Proof:** `ListingViewService` records views asynchronously, one per viewer per `ListingBusinessConstants.VIEW_DUPLICATE_WINDOW_HOURS`. Anonymous viewers are keyed by the server IP hash, never the client `sessionId`; owner and duplicate checks run before any entity load. View-stat cache keys include the requester and date range. `ListingSocialProofService` combines 24h active viewers, in-cart count, and favorite count in one payload.

## Redis & Caching
- Spring caches (`CacheConfig`, cleared by `CatalogSeedStartupRunner` / mutations): `catalog:enums`, `catalog:vehicle`, `catalog:attributeDefinitions` (DTOs only, never entities), `listing:userListings`, `listing:views:seller`, `listing:views:listing`, `listing:globalStats` (public `GET /statistics`), `listing:bestSellers`.
- Filter queries: page size clamped by `PageRequests.MAX_PAGE_SIZE`, `id` tie-breaker on every sort, COUNT skipped when the page is not full, and the `city`/`district` label `LIKE` runs only when no catalog key is sent.
- Redis keys: `v4:listing:active_viewers:{id}` (24h ZSET) and `v6:catalog:locations:*` (`LocationCatalogService`).

## API
- **Base (`ListingController`, `/api/v1/listings`):** `GET /{id}` · `DELETE /{id}` · `PUT /{id}/{publish|reactivate|deactivate|mark-sold|quantity|price}` · `POST /{id}/relist` · `GET /{listing-id}/{reviews|review-stats}` · `POST /bulks` · `POST /filter` · `GET /search` · `GET /search/listing-no/{no}` · `GET /status/{status}` · `GET /{statistics|best-sellers}`. Own listings: `GET /my` · `GET /my/status/{status}` · `GET /my/view-stats` · `GET /my/selection` (capped at `MAX_BATCH_STATUS_SIZE`) · `PUT /my/inactive/reactivate` · `PUT /my/active/deactivate`. Fee: `GET /fee-config` · `GET /fee-quote` (server fee + `sufficientBalance`) · `POST /pay-fee`. Batch: `PUT /{quantity|price|status}/batch` (all or nothing).
- **Views (`ListingViewController`, `/api/v1/listings`):** `POST /{id}/view` · `GET /{id}/{view-stats|active-viewers|social-proof}`.
- **Verticals (`/api/v1/{vehicles|electronics|real-estates|books|clothing|sports}`):** `POST /create-listing` · `PUT /{id}` · `GET /{id}` · `POST /filter`. Extra lookups: vehicles `GET /brand/{brand-id}/model/{model-id}`, electronics `GET /electronic-types/{electronic-type-id}`, clothing `GET /brands/{brand-id}/types/{clothing-type-id}`.
- **Catalog (`/api/v1/catalog`, `@PublicEndpoint` except the real-estate `specs/*` lookups):** `GET /vehicle/{types|brands|models|generations|versions|trims|attributes}` · `GET /electronics/{models/{modelId}|attributes}` · `GET /real-estate/{specs/room-configs|specs/zoning-statuses|attributes}` · `GET /books/{editions|search|attributes}` · `GET /clothing/attributes` · `GET /locations/{cities|districts|neighborhoods}`.
- **Price History (`/api/v1/price-history/listing/{listing-id}`):** `GET /` · `GET /latest` · `GET /exists`.
