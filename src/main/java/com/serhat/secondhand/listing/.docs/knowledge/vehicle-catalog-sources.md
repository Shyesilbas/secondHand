# Vehicle Catalog Data: Rules and Sources

Seed files live in `src/main/resources/data/vehicles/` (git-ignored, kept locally). This note records how version data is filled so it can be checked and extended.

## Rules
- A field is filled only when sources agree; otherwise it stays `null`. The snapshotter keeps the seller's value for a `null` catalog field, so an empty field never overwrites a listing with a guess.
- `source: "verified"`: power, torque and gearbox confirmed by at least two independent sources (manufacturer data or Turkish press/spec sites). Anything else is `claude-draft`.
- Version `startYear`/`endYear` are set only when the Turkish sale period is certain; otherwise the generation's years apply. A wrong range would reject real listings.
- Hybrid system torque is left empty: manufacturers publish engine and motor torque separately, and sources sum them differently.
- Generation names are not changed (the id is derived from the name); corrected years go into `startYear`/`endYear`.
- Mild hybrids (48V eTSI, Duster mild hybrid) are `GASOLINE`; full and plug-in hybrids are `HYBRID`. DCT/EDC/DSG, torque-converter automatics and e-CVT are `AUTOMATIC`; belt CVTs (X-Tronic, Multidrive S) are `CVT`; single-clutch automated manuals (Easy-R) are `SEMI_AUTOMATIC`.
